You are a senior full-stack engineer building a production-ready mobile MVP for a Cyprus futsal booking platform.

Product name
FutsalCY (working name)

App structure (important)
This is ONE mobile app (React Native + Expo).
On first open (and any time before login), the user must choose:

Continue as Player
Continue as Venue Owner
(Hidden/secondary) Admin Login (e.g., small link on the login screen)
After the user chooses Player vs Venue Owner, the authentication screens are the same (email/password), but once logged in the navigation stack and available views must change based on the chosen role + the user’s actual role returned by the backend.

Rules:

If a user logs in as an account whose backend role does not match the selected mode, show an error and offer to switch mode.
Persist the last selected mode locally (so next app open remembers Player vs Owner).
Goal
Build an MVP I can demo to futsal venues in Cyprus and run a pilot with 2–3 venues. The wedge is venue operations: live availability, bookings, deposit/full payments, cancellations/refunds basics, owner calendar, and settlement reporting. Everything else (matchmaking, teams, stats, tournaments/birthday parties) is secondary and must NOT block MVP completion.
