---
name: pnpm audit major-version overrides
description: Guard against pnpm audit fixes selecting incompatible major versions in range-valued overrides.
---

Treat range-valued overrides generated by `pnpm audit --fix` as security recommendations, not guaranteed compatibility-safe resolutions. Constrain them to a patched version within the consuming framework's supported major when the generated range can cross a major boundary.

**Why:** An audit-generated Babel override used an open-ended minimum range, which selected Babel 8 and broke Expo 54 bundling even though a patched Babel 7 release was available.

**How to apply:** After any pnpm audit fix, inspect peer/compatibility warnings and runtime bundles. Replace open-ended override values with the lowest patched compatible version when a framework pins or expects a specific major.
